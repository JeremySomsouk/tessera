`tessera-banner.png` — 2172 × 724 PNG, 3:1 aspect ratio.

The redesigned README banner shares the application's tiled T monogram, ink-blue/slate backing, sea-glass mint, and amber attention accent. It is also reusable as a wide portfolio preview. Use `object-fit: cover` with left-center positioning for narrower containers; keep the title accessible outside the image. Website placement is not changed by this PR.

Generated with the built-in ImageGen tool, using the redesigned icon as a brand reference. Final design prompt:

> Use case: ads-marketing. Asset type: final wide 3:1 GitHub README banner and reusable portfolio preview for Tessera. Create a single production-ready horizontal graphic, 3072 by 1024 or equivalent exact 3:1 composition. The reference image is the newly redesigned Tessera application icon: preserve its architectural three-tile T monogram, sea-glass mint, small amber attention tile, and ink-blue/slate identity, but do not put a rounded-square app-icon backing in the banner. Scene/backdrop: clean flat deep ink-blue (#12171e), with extremely subtle fine slate construction lines. Composition: generous controlled left/right breathing room, all important content inside a central crop-safe area occupying the middle 78 percent of width and 65 percent of height. A compact large tiled T monogram to the left of the exact title 'Tessera', set in finely crafted modern sans-serif typography, warm off-white, medium weight, precise kerning. To the right, extend the tessera geometry into a striking restrained mosaic of three terminal-pane rectangles with narrow negative-space channels and one amber focused tile. The shapes should read as organized work gathered into one workspace, with architectural asymmetry and quiet precision. Preserve the matte mint and amber tile material; reduce 3D depth compared with the icon so this feels editorial, refined, graphic, and coherent with a dense native developer tool. Text (verbatim): 'Tessera'. Only this one word, spelled T e s s e r a. No subtitle, slogan, version, code, chevrons, fake UI, buttons, robots, laptop, neon, purple, glass, decorative blobs, excessive gradients, noisy texture, floating shadow, borders around the whole banner, or watermark. Full-bleed opaque backdrop; no white or transparent margins. Professional banner artwork, not a mockup or a collage of design options.

# Application icon

`app-icon.png` — 1024 × 1024 RGBA PNG. A three-tile T monogram: mint crossbar and stem, with an amber tile completing the crossbar. It sits on an ink-blue matte backing with genuine transparency outside the icon. `app-icon-window.png` is its 256 × 256 native viewport export. The toolbar uses the same three-tile geometry in a small code-drawn mark.

The existing macOS bundle script derives the standard 16/32/128/256/512 pixel icon family at 1×/2× using `sips`, builds `Contents/Resources/Tessera.icns` with `iconutil`, and declares it through `CFBundleIconFile`. Bundle validation decodes the ICNS back to an iconset before signing. Both Intel and Apple Silicon use the same artwork; no runtime dependency was added.

Created with the built-in ImageGen tool, using the prior Mosaic icon as a brand reference. The generated artwork was resized only to produce the packaging exports; its alpha was preserved. Final design prompt:

> Use case: logo-brand. Asset type: one final 1024x1024 native desktop application icon for Tessera, a crafted Rust terminal workspace for supervising Claude Code and Codex sessions. The input image is a brand reference only; redesign the composition substantially. The redesigned app uses deep blue-slate surfaces and restrained sea-glass mint accents. Create a distinctive architectural tessera monogram: a bold uppercase-T silhouette assembled from three crisply cut mineral tiles with deliberate narrow dark negative-space channels. A wide mint horizontal top tile, a tall mint central stem below, and a small warm amber square tessera completing the upper-right end of the crossbar. The tiled T is broad, compact, balanced, highly readable at 32 pixels, with confident proportions and precise almost-square tile corners. Center the symbol on a dark ink-blue macOS rounded-square backing, softly beveled matte ceramic material, subtle restrained depth and controlled lighting. Backing occupies about 84 percent of the square canvas; equal transparent margins on every side, genuine alpha outside the backing, no shadow outside it. Front-facing orthographic composition, polished production asset. No extra text, terminal chevron, code, numbers, letters besides the abstract tiled T monogram, robots, neon, metallic gloss, glass, gradients-as-decoration, texture grain, watermarks, mockup or icon collection. The result should feel like a purposeful, premium developer tool rather than an AI illustration.

# Terminal symbol fallback

`fonts/NotoSansSymbols2-Regular.ttf` is the unmodified Noto Sans Symbols 2 font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssymbols2), distributed under the SIL Open Font License in `fonts/OFL-NotoSansSymbols2.txt`. It is embedded as the last monospace fallback to render shell prompt symbols such as `✗` (U+2717), without replacing Hack for ordinary text. No system font installation or runtime download is required.
