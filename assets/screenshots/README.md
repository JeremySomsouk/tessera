# README screenshots

Captured from the Tessera 0.9.0 macOS application at 1180 × 760 logical pixels.

- `terminal.png`: a real terminal displaying fictional task notes, with a generic shell prompt.
- `work.png`: the real Work view populated with fictional Atlas, Fieldnotes, and Orbit work items.

These are application captures, not generated interface mockups. The demo used a separate temporary home and `TESSERA_STATE_PATH`, with no personal work history, agent credentials, or real agent conversations. Project paths under `/projects` are illustrative. The terminal output is sample text, not evidence of an agent run or completed checks.

For future captures, use an isolated state file and a plain shell prompt, then inspect every visible path, title, and terminal line before publishing. Keep images in PNG format and update their README captions when the interface changes.
