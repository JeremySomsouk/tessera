# 0.7.0

- On macOS, Command+Enter inserts a newline in Claude Code by sending the same line-feed character as Ctrl+J. Plain Enter still submits, and Command+Shift+Enter still maximizes or restores the pane.
- Middle-click a terminal workspace tab to stop its focused terminal. This works in the horizontal tabs and workspace sidebar, follows the existing close-confirmation setting, and does not switch to a background workspace first.

Command+Enter sends a line feed to the terminal application; applications with custom Ctrl+J bindings may handle it differently. This shortcut does not require Claude Code terminal setup or extended keyboard protocol support.
