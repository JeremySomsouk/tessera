# 0.7.1

- Select text in a terminal, right-click, and choose **Copy without indentation** to remove leading spaces and tabs from each selected line. Line breaks and the rest of the text are preserved.
- Regular **Copy** and Command+C keep their existing behavior, preserving indentation for code and other formatted text.

The new action removes all leading indentation, including nested code indentation. Use regular Copy when that spacing matters.
