Tessera 0.3.0 redesigns the desktop workspace and makes installation simpler.

- **New desktop interface:** coordinated dark and light themes, a compact workspace rail on wide windows, scrolling tabs on narrow windows, and workspace-level split and maximize controls.
- **Searchable command center:** find workspaces by name or directory, run actions with the keyboard, create a workspace in a dedicated form, and open grouped Settings. Search and primary actions stay visible in small windows.
- **Clearer Overview:** denser session lists, relative activity timestamps, and separate Sessions/Activity views in narrow windows. Filters keep selection within the visible results; double-click a session to return to its terminal.
- **New identity:** a mint-and-amber tiled T app icon, matching toolbar mark, and a new README/portfolio banner.
- **Simpler documentation:** a shorter README for installation and everyday use, with detailed controls, development, and release instructions in dedicated guides.
- **One-command installation:** verified prebuilt downloads for macOS and Linux on x86-64 and ARM64, without Rust or administrator privileges.

Install or update with:

```sh
curl -fsSL https://github.com/JeremySomsouk/tessera/releases/latest/download/install.sh | sh
```

The macOS app installs in `~/Applications/Tessera.app` with its signed automatic updater; existing updater-enabled installations can receive 0.3.0 on quit. Linux installs in `~/.local/bin`; rerun the installer to update. Agent hooks remain an explicit installation step.

Preferences and session history remain compatible. Every launch starts a fresh terminal; previous layouts are not restored. macOS bundles remain ad hoc signed, not Apple-notarized. Tessera remains an alpha; native terminal and assistive-technology acceptance checks are documented in [terminal compatibility](https://github.com/JeremySomsouk/tessera/blob/v0.3.0/docs/terminal-compatibility.md).
