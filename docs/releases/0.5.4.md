# 0.5.4

- Delete specifications with confirmation and clear disconnected Claude or Codex session history from Overview. Working directories and terminals are preserved.
- Resize the workspace sidebar and retain its width. Header controls use consistent sizing and spacing.
- Prevent split creation and removal from corrupting shell prompts by synchronizing PTY and grid resizing and ignoring provisional layouts.
- Automatically detect installed terminal fonts from iTerm2, Terminal.app, or an explicit kitty font setting. Installed Nerd Fonts and bundled Unicode and monochrome emoji provide fallback icons.

Font discovery currently reads default profiles and direct kitty settings. Other terminal configurations and included kitty files are not supported yet.

Release status: prepared for review, not published. Native macOS and Linux acceptance checks remain pending, including split resizing and Claude footer rendering.
