# Tessera 0.13.0

- Identify terminal panes locally, with directory, process state and pane actions.
- Start a shell, Claude Code or Codex from New workspace. Existing shell and Claude folder shortcuts remain available.
- Cycle through sessions needing attention and return to the originating terminal. Agent completion still does not accept work; approvals remain in the CLI.
- Show scrollback and selection modes explicitly, with a Return to live action. Selection insertion is labelled separately from clipboard paste.
- Retry a saved conversation without stopping the fallback shell, using a new workspace. Saved output stays read-only and separate from live output.
- Include the terminal performance improvements: ordered large-paste transport, responsive controls under output load, bounded shared rendering waits, and reduced selection and snapshot copying. See [measurement boundaries and remaining limits](../terminal-performance.md).

This release remains an alpha. Native accessibility, full IME preedit and the terminal protocol gaps listed in [compatibility](../terminal-compatibility.md) remain limitations.
