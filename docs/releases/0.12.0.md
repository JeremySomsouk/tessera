# 0.12.0

- Promote Remote runs into the native **Autobot** page beside Terminal and Work. Follow multiple ticket keys, open a ticket from Work, and inspect runs grouped by configured source and repository.
- Surface failed runs and repository errors, retain stale metadata after refresh failures, and preserve selection as new results arrive. Run timelines use GitHub states and known job/step progress without treating completion as accepted work.
- Add optional live refresh while Autobot is visible, off by default, with conservative scheduling, error backoff, cancellation, and the existing shared request limit.
- Edit and validate source configuration in Settings. Save only configuration, ticket keys, and tracking preferences; metadata remains in memory.
- Preserve terminal output privacy and the separate full-preview and explicit-confirmation steps for pull request comments. Authentication stays with `gh`; Autobot cannot approve or merge pull requests or change auto-merge settings.

- Add native Merge Radar pull request triage with review queues, repository/team filters, bot grouping, saved snoozes, and browser/copy actions.

Native interactive and authenticated GitHub acceptance remain pending.
