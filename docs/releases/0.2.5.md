Tessera 0.2.5 improves terminal and workspace lifecycle behavior.

- **Fresh startup:** every launch opens one new terminal. Workspace resume is removed; preferences and session history remain saved.
- **Named workspaces:** creation has a separate optional name field. Enter creates the workspace from either field, and invalid directories retain the name for retry.
- **Split directories:** both split directions inherit the focused shell’s current directory, including changes made with `cd`.
- **Prompt symbols:** a bundled symbol font renders Unicode crosses such as `✗` and checkmarks while preserving normal terminal text and cell sizing.
- **Shell exit:** Ctrl+D at an empty shell prompt or `exit` closes that pane automatically. Exiting the last pane closes its workspace, preserving surviving tabs and session history.
- **Command panel:** Escape or clicking outside Workspace & commands dismisses it. The panel remains scrollable on smaller windows.

Existing updater-enabled installations can receive this release through the signed updater. For manual installation, download `Tessera-arm64.dmg` for Apple Silicon or `Tessera-x86_64.dmg` for Intel, quit Tessera, and replace the application in Applications. Bundles remain ad hoc signed and are not Apple-notarized.
