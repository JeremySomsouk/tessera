# 0.6.1

- Open HTTP and HTTPS links in the default browser with Command-click or Option-click in a terminal pane.
- Recognize URLs across wrapped terminal rows and links attached to terminal hyperlink labels.
- Exclude surrounding punctuation from printed links while preserving balanced parentheses in URL paths.
- Show a pointing-hand cursor when hovering over a link with Command or Option held. Plain clicks retain selection behavior; Option-click outside links retains application mouse input.
