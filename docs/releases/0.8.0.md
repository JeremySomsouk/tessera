# 0.8.0

- Choose **Claude in folder** or press Command+Shift+L to find an existing folder by name and launch Claude Code in a focused terminal. Folder results show full paths, support keyboard selection, and accept pasted directory paths. No project registration, specification, or manual work item is required.
- On macOS, Spotlight searches indexed folders across your Mac. A bounded search of configurable roots covers indexing gaps; Linux uses those roots directly. Settings defaults to your home folder and supports up to 16 roots. Hidden folders and common dependency/build trees are skipped; paste a path or choose a specific root to reach them.
- Workspace paths and active-pane indicators are easier to read. The header and footer follow the selected theme, pane controls share a **Pane** menu, and **Settings** is available from the header or `Command+,`.
- Folder launches keep the selected physical working directory even when shell startup files change it. Missing or deleted folders are never created, and failed Claude launches retain actionable terminal output. Hooks and ordinary Claude Code approvals remain in effect.

On Linux, replace Command with Ctrl+Alt. Folder search is bounded and may omit inaccessible, unindexed, or deeply nested locations; the picker explains its coverage and limits. Claude Code must already be available in the supported login shell's PATH.
