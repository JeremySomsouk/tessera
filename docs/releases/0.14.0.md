# Tessera 0.14.0

- Prepare Git branches before starting Claude Code or Codex, and manage them later from each local terminal’s **Git** button.
- Fetch origin, switch to the default branch with **gcm**, pull with **gl**, and search local and origin branches. Selecting a remote branch creates a local tracking branch when needed.
- Pulls only fast-forward. Branch changes use Git’s normal protections for uncommitted work, and Git commands run separately from agent terminal input.
- Return from Git to the prepared folder or **Create workspace**, then press Enter to launch with your choices preserved. Git preparation errors do not block launching.
