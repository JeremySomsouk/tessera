Tessera 0.2.6 improves terminal text selection and simplifies workspace controls.

- **Direct selection:** drag to select terminal text without holding Shift, including in Codex mouse-reporting screens. Option/Alt-click remains available for application mouse input.
- **Selected-text actions:** right-click a selection to copy it, paste it into the current terminal, open it in a new terminal tab, or search for it in your browser. Terminal actions add no Enter; new tabs inherit the source terminal’s current directory.
- **Compact terminal controls:** the permanent per-pane toolbar is removed. Find, keyboard selection, and stopping the focused pane remain available through shortcuts and workspace-tab context menus.
- **Clearer workspace chrome:** roomier tabs, a distinct active underline, and a readable shortcut bar improve scanning in both themes and narrow windows.

Existing updater-enabled installations can receive this release through the signed updater. For manual installation, download `Tessera-arm64.dmg` for Apple Silicon or `Tessera-x86_64.dmg` for Intel, quit Tessera, and replace the application in Applications. Bundles remain ad hoc signed and are not Apple-notarized.
