# 0.5.2

- **Terminal:** reclaim space below the pane title, select a complete whitespace-delimited word on double-click, and keep the last rendered frame visible while terminal output is being parsed.
- **New workspaces from Specs:** create missing working directories when launching an agent, including paths using `~`. Root-level paths that macOS cannot write to receive a home-directory correction, without assuming a `~/projects` folder.
- **Created directory tracking:** save each newly created workspace target's canonical path and creation time in workspace configuration. Existing directories and intermediate parent folders are not recorded. Entries persist across restarts to support later review and cleanup; Tessera does not delete them automatically.

Release status: prepared for review, not published. Native Claude visual acceptance and installed updater verification remain pending.
