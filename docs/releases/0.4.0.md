# Tessera 0.4.0

Prepare tasks in a local Markdown specification board, then launch Claude or Codex with the exact specification revision pinned to the terminal session.

- Draft, Ready and In progress cards with title, working directory and Markdown scope.
- Immutable, deduplicated revision history and exact launch-context preview.
- Claude/Codex launches in a new real PTY; Codex uses --no-daemon.
- Overview links agent sessions back to their specification and revision; cards reopen retained terminals.
- Agent terminal output remains available after exit until explicitly closed. Failed launches show the exit code and recovery guidance, and return the card to Ready when no other launch is running.
- Workspace navigation and command actions leave Specs consistently. Empty fields and invalid directories explain disabled launch actions.

Open Specs with Cmd+Shift+S on macOS or Ctrl+Alt+Shift+S on Linux. Agent completion never accepts a specification automatically. Specifications, revisions and launch results are stored locally with existing preferences. Launch context is limited to 8000 bytes; cards retain up to 256 revisions and launches.

Existing preferences and session history remain compatible. Hook installation is still explicit. Every app launch opens a fresh shell; live panes are not restored. Native Mac interactive/accessibility acceptance remains pending; Jira/GitHub import and agent-proposed specification amendments remain future increments.
