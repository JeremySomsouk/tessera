# Tessera 0.5.0

Review scope changes before applying them, and recover earlier specifications without losing current work.

- Propose a change: edit or paste a replacement beside its saved base, then accept or cancel. Advanced controls accept an individual field. Proposals survive restart; concurrent edits block acceptance.
- Revision history: compare saved versions with the current draft and restore as a new revision. Unsaved work is saved first, and launch contexts remain pinned.

Existing 0.4.0 metadata loads without conversion. Agent proposal ingestion remains manual. No new dependencies, network requests or hook changes.

Release status: prepared locally, not published. Intel/Apple Silicon CI, native interactive review/restore acceptance and installed updater verification remain required before release readiness.

Native checklist: propose and accept a scope; cancel without changes; edit the draft during review and confirm conflict; restart with a pending proposal; restore an old version while preserving unsaved work; confirm a running agent still references its original revision. Repeat at minimum window size and in both themes.
