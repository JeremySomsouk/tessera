# 0.9.0

- Work now shows attention and activity counts, searchable work cards, clearer statuses and next actions, and a more focused detail view. New work uses the active workspace folder and opens its title for editing.
- Open an attached terminal, review disconnected session activity, or create and reuse a specification directly from a work item. Keyboard navigation keeps the selected work visible.
- Configure search roots directly on Claude in folder or in Settings. Folder-name searches, including Spotlight on macOS, stay inside those roots and their subfolders. Exact pasted directory paths can still open folders outside the roots.
- Search roots remain user preferences. An empty setting uses the home folder; no personal project path is built in.
