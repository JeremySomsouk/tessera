# Tessera 0.13.1

- Label each terminal menu **Pane**, replacing an unsupported ellipsis glyph that could appear as an empty square.
- Choose Default, Ocean, Forest, or Plum workspace colors in Settings, independently of Light/Dark appearance. The saved choice updates workspace chrome and focus accents; terminal ANSI colors remain unchanged.
- Includes the terminal redesign and performance improvements from [0.13.0](0.13.0.md).
