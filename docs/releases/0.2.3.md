Tessera 0.2.3 improves terminal cursors, adds screenshot file drops and makes update failures visible.

- **Readable block cursors:** a solid cursor redraws the character with contrasting text instead of tinting over it.
- **Wide characters:** block, outline and underline cursors cover the full character width, including combining marks.
- **Consistent positioning:** cursors stay clipped to their terminal pane and visible rows; terminal search and copy-mode transitions suppress conflicting cursors. Vim's requested shapes and visibility remain respected.
- **Packaging:** includes the bundled Sparkle license and third-party notices.
- **Update controls:** Workspace & commands scrolls when needed. If the updater fails to start, a disabled check button and the failure reason remain visible instead of hiding the controls.
- **Screenshot drops:** dropping saved images or files onto a terminal pastes escaped paths into that pane. Each image uses a separate bracketed paste for Codex attachment recognition; drops never press Enter. Find and copy mode prevent file-drop input.

From an installed 0.2.2, open Workspace & commands → Check for updates to test the signed updater. Automatic checks and downloads also run in the background; installation happens when you quit Tessera. Save terminal work before quitting. Direct downloads are available for Intel and Apple Silicon Macs. The app remains ad hoc signed.
