# Tessera 0.15.0

- Choose independent **App theme** and **Terminal theme** settings, each with Dark and Light modes.
- Light terminal mode changes the pane background, default text, cursor, and selection colors while preserving colors explicitly set by zsh themes and terminal applications.
- Save the terminal theme across restarts and apply it immediately to all panes and windows. Existing installations retain dark terminal panes until the setting is changed.
- Terminal color queries report the selected theme, including application overrides, so programs can detect the current background.
- Prevent cached output from briefly retaining colors from the previous terminal theme while the terminal is busy.
