Tessera 0.2.0 adds terminal search and keyboard selection, with fixes from native macOS feedback.

- **Terminal search:** Cmd+F or Find searches each pane's retained output. Enter / Shift+Enter navigate matches; Escape restores terminal input. Searches run off the UI thread and discard stale results.
- **Keyboard selection:** Cmd+Shift+Space or Select enters copy mode. Arrows and paging navigate, Shift extends, Space toggles selection, Enter copies and returns. Text, paste and IME commits stay out of the shell while selecting.
- **Typing caret:** normal typing uses a slim beam. Applications can request block, underline, beam or hidden cursors.
- **Codex contrast:** fixed background-color queries incorrectly reporting a near-white background in the dark terminal. Application color overrides are also reflected in replies.
- **Workspace controls:** Enter creates a workspace from the directory field or opens the first filtered match. Invalid directories retain the dialog without creating a pane.
- **Shortcuts and chrome:** number shortcuts support physical digit keys independently of workspace names; stacked splits use the correct shortcut. Hover tips show shortcuts. Buttons have softer corners and modest padding.

Download the DMG for your Mac: `Tessera-arm64.dmg` for Apple Silicon or `Tessera-x86_64.dmg` for Intel. Open it and drag Tessera to Applications. Restart Tessera and Codex to use the corrected terminal color detection.

This remains an alpha. Search omits combining marks, terminal cursor blinking and native accessibility acceptance remain unfinished, and quitting stops hosted shells. No detached host, specification editor or issue connector is included. Hook configuration and CLI approval decisions remain under your control.
