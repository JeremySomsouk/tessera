Tessera 0.2.2 adds automatic macOS updates and improves daily terminal use.

- **Automatic updates:** the macOS app checks on launch and daily, verifies signed releases, downloads in the background, and installs when you quit. Workspace & commands includes manual update checks and automatic-update preferences. Install this version manually once to enable future updates.
- **Rename workspace:** Cmd+Shift+R selects the current name. Enter saves, Escape cancels, and blank names are rejected.
- **Terminal close preference:** Cmd+W and the close button share a “Don’t ask again for any terminal” checkbox. The preference applies to all workspaces and survives restarts; prompts can be re-enabled in Workspace & commands.
- **Trackpad scrolling:** small gesture movements accumulate instead of disappearing. Mouse-reporting programs receive wheel events, including Codex's fullscreen transcript. Alternate-screen programs that request alternate scrolling receive cursor keys. Shift preserves native scrollback.

- **New terminals:** Cmd+N and Cmd+T open a terminal workspace in the active pane’s current directory, including after `cd`.
- **Live input:** typing and pasting return the terminal from scrollback to the current input.
- **Codex questions:** enable “Clickable Codex questions” in Workspace & commands to select an option by clicking; Enter confirms.

Download `Tessera-arm64.dmg` for Apple Silicon or `Tessera-x86_64.dmg` for Intel. Quit Tessera, open the DMG, and drag Tessera to Applications to replace the previous version. This initial update is still ad hoc signed and may require macOS approval; it is not Apple-notarized. Later releases can install through the built-in signed updater.
