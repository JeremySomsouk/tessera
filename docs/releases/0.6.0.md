# 0.6.0

- Replace the session-centric Overview with Work: an attention queue, active work, and separate retained history.
- Keep developer stages (Define, Plan, Build, Verify, Review, Deliver) independent of agent activity. Stage and completion decisions remain explicit; an agent response never accepts the work.
- Group Claude Code and Codex sessions around durable work items. Preserve titles, directories, linked specifications and session associations after terminals close or Tessera restarts.
- Bring specification editing and revision review into the selected work item. Existing specifications, proposals, revisions and launch links migrate without losing their saved content.
- Keep new responses visible until inspected, prioritize observed permission/input requests, and move raw hook events into tracking details.

Work stage labels do not certify tests, code review or delivery. Git evidence, verification records tied to code snapshots, provider session resume, and richer provider protocols remain future increments. Terminals still start fresh when the application restarts; retained work does not reconnect an old process.
