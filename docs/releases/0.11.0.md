# 0.11.0

- Reopen Tessera with your previous windows, tab membership and active tabs, pane splits, focused panes, window positions and sizes, and latest working directories restored automatically.
- Continue Claude Code and Codex conversations using each pane's saved session identity. If continuation fails, keep the conversation identity and saved output, open a fresh shell, and offer a retry.
- Keep up to 2,000 lines or 256 KiB of saved output per pane in a separate read-only history view. Saved terminal escape sequences cannot trigger terminal replies or execute commands.
- Ordinary terminal panes reopen as fresh shells. Commands and typed input are never replayed. Explicitly closed panes and windows stay closed; quitting preserves the open workspace.
- Save snapshots periodically and on clean exit with atomic writes, recovery backups, and migration of older state files.
