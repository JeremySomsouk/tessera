# 0.5.3

- **Agent choices:** click numbered Claude Code responses to select them, then press Enter to submit. Claude Code and Codex choice clicks default on; explicitly saved opt-outs remain respected. Text entry and unsupported prompt layouts remain keyboard-only.
- **macOS navigation:** combine native window controls and navigation in one compact dark bar. Drag empty bar space to move the window or double-click it to maximize. The active workspace name and split/maximize actions move into the bar, removing the duplicate terminal heading. Narrow windows omit the brand label and place pane actions in the workspace-name menu to keep navigation accessible. Other platforms retain native titlebars.

Release status: prepared for review, not published. Native macOS traffic-light alignment, window dragging, fullscreen behavior and Claude visual acceptance remain pending.
