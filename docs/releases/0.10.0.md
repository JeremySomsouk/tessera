# 0.10.0

- Drag a workspace tab or rail entry outside its window and release to move it into a new window at the drop point. Running shells, scrollback, split panes, and agent links stay intact. Moving the last tab out closes the source window.
- Open a fresh terminal window in the focused shell's current directory with Cmd+Shift+T on macOS, Ctrl+Alt+Shift+T on Linux, or **New terminal window** in Commands. A tab's context menu also offers **Move to new window**.
- Workspace number shortcuts stay within the current window. Commands and Work links bring the terminal's owning window forward. Closing a window stops its terminals while other windows keep running; closing the final window quits Tessera.
- Windows share one application process. This release does not restore windows or reconnect terminals after quitting.
