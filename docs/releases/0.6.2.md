# 0.6.2

- Click a recognized Claude Code or Codex answer to select and submit it immediately. Clicking the highlighted answer submits it without moving the selection.
- Recognize question choices when terminal applications enable mouse reporting.
- Recognize keyboard-help footers split across up to three rows in narrow terminal panes, without treating numbered answer labels as footer instructions.

Clickable choices still require a visible numbered prompt with its selection marker and supported keyboard-help footer. Notes entry, scrollback, search, copy mode, and unsupported permission dialogs remain keyboard-only.
