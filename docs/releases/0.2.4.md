Tessera 0.2.4 adds screenshot file drops and makes missing update controls diagnosable.

- **Screenshot drops:** dropping saved images or files onto a running terminal pastes escaped paths into that pane. Each image uses a separate bracketed paste for Codex attachment recognition; drops never press Enter. Find, copy mode and dialogs block file-drop input. If a screenshot preview supplies no path, save it and drop the saved file.
- **Update controls:** Workspace & commands scrolls when needed. If the updater fails to start, a disabled check button and the failure reason remain visible instead of hiding the controls. Startup diagnostics survive unrelated terminal errors.

Existing updater-enabled installations can receive this release through the signed updater. For manual installation, download `Tessera-arm64.dmg` for Apple Silicon or `Tessera-x86_64.dmg` for Intel, quit Tessera, and replace the application in Applications. Bundles remain ad hoc signed and are not Apple-notarized.
