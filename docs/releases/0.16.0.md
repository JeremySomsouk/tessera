# Tessera 0.16.0

- Read earlier terminal output while new lines arrive. Each pane keeps its reading position. **Peek** previews the newest lines in wider panes, and **Return to live** restores keyboard focus.
- Select and copy text while a full-screen assistant redraws. The selected page stays available until you resume the live view. Fast drags and visually wrapped lines are handled more reliably.
- Paste multiline text into Claude Code and Codex as a single bracketed paste when supported. In other programs, review line breaks before sending them, including a trailing newline.
- Spot the focused terminal from its outline and see how far back you are in its history. Narrow panes keep the working directory and pane actions within reach.
- Reduce terminal frame construction time during streaming, scrolling and pane switching. Background panes continue processing output without requesting a repaint for each batch.
